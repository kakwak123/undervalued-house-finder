# Supabase Database Setup

This guide explains how to set up the Supabase database for the ingestion system.

## Quick Setup

### Option 1: Supabase Dashboard (Recommended)

1. Go to [Supabase Dashboard](https://supabase.com/dashboard)
2. Select your project
3. Navigate to **SQL Editor**
4. Copy the contents of `supabase_schema.sql`
5. Paste into the SQL editor
6. Click **Run** to execute

### Option 2: Verify Tables Exist

Run the setup script to check if tables already exist:

```bash
cd ingestion
poetry install
poetry run python setup_database.py
```

## Database Schema

The system requires two main tables:

### `listings` Table

Stores property listing data with:

- Primary key: `listing_id` (TEXT)
- Property details: suburb, property_type, bedrooms, bathrooms, etc.
- Pricing: current_price, previous_price
- Status: status, auction_datetime
- History: price_history (JSONB), auction_history (JSONB)
- Address: address (JSONB)
- Timestamps: created_at, updated_at

### `events` Table

Stores events generated by the system:

- Primary key: `id` (UUID, auto-generated)
- Event details: event_type, timestamp, listing_id
- Metadata: metadata (JSONB)
- Timestamp: created_at

## Indexes

The schema creates indexes for efficient querying:

- `idx_listings_suburb` - Query by suburb
- `idx_listings_status` - Query by status
- `idx_listings_source` - Query by source
- `idx_events_listing_id` - Query events by listing
- `idx_events_event_type` - Query events by type
- `idx_events_timestamp` - Query events by time

## Configuration

Copy `.env.example` to `.env` in the `ingestion/` directory and fill in your credentials:

```bash
export SUPABASE_URL="https://your-project.supabase.co"
export SUPABASE_KEY="your-anon-key"
```

Or `.env` file:

```
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your-anon-key
```

## Testing the Setup

After creating the tables, test the ingestion:

```bash
cd ingestion
poetry run python -m ingestion.cli ../testdata/search.json
```

This will:

1. Read listings from the JSON file
2. Normalize the data
3. Upsert into Supabase
4. Generate events for any changes
5. Display statistics

## Troubleshooting

### Tables Don't Exist

If you get errors about tables not existing:

1. Run the SQL schema in Supabase dashboard
2. Verify tables were created in the Table Editor
3. Check that RLS policies allow access (if RLS is enabled)

### Permission Errors

If you get permission errors:

1. Check that you're using the correct API key
2. Verify RLS policies allow your operations
3. Consider using service_role key for setup (not recommended for production)

### Connection Errors

If you can't connect:

1. Verify the Supabase URL is correct
2. Check your internet connection
3. Verify the API key is valid
